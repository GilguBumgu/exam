Firebase 문제은행 설정

Firebase 콘솔(console.firebase.google.com)에서 무료 프로젝트를 만들고
"프로젝트 설정 → 일반 → 내 앱 → SDK 설정 및 구성"에서 나오는
config 객체(중괄호 { } 포함)를 그대로 붙여넣으세요.

Firestore와 Authentication(익명 로그인 사용 설정)도 콘솔에서 미리 켜두어야 합니다.
